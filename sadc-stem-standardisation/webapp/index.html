    About this framework

    Each dimension is scored 0-4 against the SADC STEM standardisation maturity scale (Absent → Emerging → Developing → Established → Advanced). Scores are illustrative baselines derived from regional policy analysis (SADCQF, UNESCO/HAQAA, SADC Teacher Standards) and are meant to be replaced with verified national data over time — see docs/METHODOLOGY.md for the full write-up and data/assessments.json for the current dataset.

    SADC Harmonised Identification Number — format validator (demo)

    Built on South Africa's Home Affairs ID model (embedded birth date + Luhn check digit), extended with a 2-digit SADC country code and a standardised sex digit moved to the end (ISO/IEC 5218) — see framework/identification.json for the full field layout (YYMMDD SSS CC Z X). This only checks whether a number is well-formed and decodes the fields already encoded in it — it cannot and does not determine anyone's identity or origin from nothing. Use synthetic/test numbers only — never enter a real person's ID number.

    About this framework

    Each dimension is scored 0-4 against the SADC STEM standardisation maturity scale (Absent → Emerging → Developing → Established → Advanced). Scores are illustrative baselines derived from regional policy analysis (SADCQF, UNESCO/HAQAA, SADC Teacher Standards) and are meant to be replaced with verified national data over time — see docs/METHODOLOGY.md for the full write-up and data/assessments.json for the current dataset.
